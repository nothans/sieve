    How it works

    1. Describe what you are looking for, in plain words. A short phrase in the words the items themselves would use works best; keywords work less well.
    2. Every item gets the same question. The model answers each one with a probability.
    3. Read the ranking. Open any result to see what the model read and why it scored that way, find items related to it, or narrow the list with a follow-up question.

    Backend

    Where Sieve sends its questions. Jev runs in the cloud through OpenRouter or TypeSafe; a local server (Kev, Laya, openjev) keeps your notes on this machine. Keys are read from environment variables or the .env file and never stored here. Click a backend to see its settings; Save and use switches Sieve to it.
